## 3. 每阶段固定流程（V4 02 第八章）

阅读阶段指令 → 检查前置 → 检查已有代码 → 修改计划 → Git 回滚点 → 编码 → 真实数据测试 → pytest → 独立数值复算 → 图表/CSV 检查 → 归档 → STAGE_Sxx.md → 更新总索引 → 停止等验收。

每阶段交付物固定包含：代码、运行命令与结果、pytest 结果（PASS/FAIL/SKIP/BLOCKED 分列）、真实样本复核记录、界面或产物证据、失败与阻断项、配色校验输出（涉图阶段）、Git 回滚点。
