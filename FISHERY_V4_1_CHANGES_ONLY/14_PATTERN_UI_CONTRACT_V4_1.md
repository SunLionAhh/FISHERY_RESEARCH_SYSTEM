## A. 用户进入页面必须得到什么

主入口名为“规律与时空总览”，也可从单设备、空间分析或图表中心进入同一状态。页面不是先给用户大量图片再让用户自己猜规律。

| 顺序 | 页面区域 | 必交付行为 |
| --- | --- | --- |
| 1 | 全局筛选与质量摘要 | 设备、日期/日期集合、日内时段、指标、水层、环境条件、数据集/运行版本、时间分辨率、对比口径；显示有效日/日历日、覆盖、配置变更和阻断 |
| 2 | 五台规律结论卡 | 五台各有独立入口；显示已观察模式、适用范围、证据等级、验证状态和主要局限；没有规律也必须说明原因 |
| 3 | 长期热力总览 | 默认“设备×日期”，以5行显示所选全部日期；数值、NA和低覆盖状态区分；点选/框选后与下方联动 |
| 4 | 五站趋势 | 同一指标的日值曲线；可选滚动趋势，但原始日值仍可查；缺测断线，参数切换显式标记 |
| 5 | 少量阶段空间图 | 按下述分组规则展示最多9张默认小图，保持空间尺度和共同色标；可切换按日/周/月/自定义阶段 |
| 6 | 证据与单日详情 | 点规律、日期格、地图点或曲线点后，打开证据抽屉：日内曲线、出现/下降/再升时段、原始回波、截断/QC、来源和支持/反例 |

规律区默认置于长期图形上方。窄屏可以折叠卡片详情、分页空间小图，但不能隐藏证据等级与质量状态。默认首页不得生成60张单日地图；逐日全量导出仍可主动选择，由后台任务生成。

## B. 20/30/60天及任意天数的默认展示

### B1. 确定性的分组算法

N为筛选最早日到最晚日的日历跨度，含首尾，不是有效观测天数。日界按Asia/Shanghai，内部区间使用[start,end)。非连续日期保留日历位置，未选择日期与已选择但缺测日期分别标记，不能把中间缺口挤掉。

| 日历跨度N | 长期表 | 默认阶段空间图 | 示例 |
| --- | --- | --- | --- |
| 1—7天 | 设备×日期；单日可切换时段 | 每天一图，最多7张 | 7天为7张 |
| 8—31天 | 一张设备×日期热力表 | 从所选起始日开始，每7天分一组 | 20天3张、30天5张；最后一组可不足7天 |
| 32—90天 | 一张设备×日期热力表 | 从所选起始日开始，每10天分一组 | 60天6张、90天9张 |
| 超过90天 | 全时段总览，必要时横向缩放/分层载入 | 从14、30、60、90、180、365天中选择首个使ceil(N/组长)≤9的组长；均不满足时取365×ceil(N/(9×365))天 | 确保默认不超过9张；完整逐日结果仍保存 |

这里默认的是“从筛选起点起算的固定天数阶段”，不要称为自然周或自然月。用户切换“自然周”时按周一至周日；切换“自然月”时按实际月份。首尾不完整区段注明实际日期、计划天数、选中天数与各站有效天数。用户自定义超过9组时使用分页或横向浏览，不删组、不静默扩大组长。

20、30、60天热力表分别为5×20、5×30、5×60；天数很多时使用滚动/缩放，不能把日指标无提示改成周指标。视图缩略汇总必须展示新的时间分辨率及聚合方法，点击能够回到日值。

### B2. 分组是显示选择，不改研究结论

更换7天/10天/自然周视图，只改变阶段汇总图的查询和展示，不触发重新训练或偷偷改变规律规则。逐日原始指标、发现期、验证期、规律版本保持不变。组边界、日期成员列表、统计方式、实际参与设备都可查询和导出。

分组后的平均值或比例可能掩盖某天的峰值；因此阶段图与日热图同时保留。不能仅凭某周汇总偏高就宣布每天都偏高，不能仅凭两个月就宣布季节性。

## C. 热力值、聚合与比较口径

### C1. 热力值必须来自已验收指标

不得使用未定义的“AI热力分数”。每个metric_id对应唯一名称、定义、单位、分子/分母、有效域、QC和算法版本。默认展示指标由真实样本验证后确定，不把本文件示例指标强行当成所有设备的最佳科学指标。

| 指标例子 | 定义与单位 | 聚合原则 |
| --- | --- | --- |
| 候选回波出现比例 | 有至少一个候选回波的有效帧数 / 有效帧数 ×100%，% | 汇总时先分别求和分子/分母，再求比例；帧定义和识别方法须已核实 |
| 候选事件率 | 候选事件数 / 有效观测小时数，事件/小时 | 时间段交界事件按冻结归属规则防止重复计数；用有效时长，不能用日历时长 |
| 回波占用比例 | 有效域内满足条件单元数 / 有效单元数 ×100%，% | 单元及加权定义明确，跨量程/分辨率先核验可比性 |
| 信号强度汇总 | 有效域内已定义信号的均值/中位数/分位数，原始单位或已校准单位 | 不能把中位数的均值称为整体中位数；对数单位不能无说明直接当线性量平均 |

缺测、全区QC失败、截断未配置、范围映射不明均不能填0。有效域内有观测且没有候选回波时，候选计数/事件率/出现比例可为0；强度均值等其他量仍按其定义计算。

### C2. 两种阶段汇总必须区分

默认“合并有效观测”：汇总分子/分母，回答该阶段所观测记录或时长上的活动水平。另提供“典型观测日”：先计算合格日指标再按日等权均值/中位数汇总，回答典型一天如何。两者标签、方法ID、有效日数不同，不可共用一个无说明的“平均热力值”。

例：日1有1/2有效帧出现候选（50%），日2有9/10（90%）。合并比例为10/12≈83.33%；日等权均值为70%。禁止把50%+90%当140%，也不能把70%标成合并比例。

默认显示全精度计算的结果，页面四舍五入只影响显示。日、周、月和任意窗口都从可追溯分子分母或支持精确聚合的数据计算，不从图片颜色或已四舍五入表格反算。

### C3. 三种比较模式

1. **同站跨日/阶段**：固定指标与安装/截断口径；参数改变时分段或经可比性审核后提供比较。页面必须标记变更点。
2. **多站同期**：提供“各站可用观测描述”和“共同有效时段比较”。后者按选中设备在分析网格内的合格观测区间求交，保留实际配对时长、每格覆盖和设备数；无共同时间给出无法比较，不能偷偷剔除某设备。用户可明确切换设备子集重新计算。
3. **相对基线变化**：基线可以为指定日期、固定阶段或前N有效日。记录基线成员、冻结版本和截止时间。比率类指标差值用百分点；相对变化%单独命名，基线0或缺失时为NA。研究验证时不得从未来日期估计基线。

每台先按自己的人工上限硬屏蔽；不能为追求相同范围而放宽任一设备上限。相同颜色只保证同一指标数值相同，不证明各台真实鱼数或探测概率相同。跨站结论另需配置、有效域、采样、增益和算法可比性证据。

### C4. 全部图共用色标与空间基准

比例指标默认固定0—100%；事件率等无固定上限指标采用冻结参考集或用户明确设置的共同范围，保存color_scale_id、上下限、单位、线性/对数模式、越界处理。不得每幅图独立min-max归一化。超色标范围显式标记，不能静默剪去或把数据值改小。

差值图使用以0为中点的对称发散色标[-M,+M]，显示正负号和单位。切换基线后可以建立新色标版本，但同一组比较图必须共用；旧报告仍按旧色标重现。

同组空间图使用相同坐标系、地图范围、比例尺和标记尺度。点位根据该阶段有效位置；站位移动或覆盖几何改变时按版本分面或列出变更，不能将整阶段画成一个虚假固定位置。理论覆盖层可开关，和表示活动的点颜色分开图例；不得把未测海域用平滑颜色冒充已观测鱼密度。

NA、未选择、低覆盖和有效零值必须视觉可区分。低覆盖阈值由分析计划冻结；未冻结时可以显示描述数据及质量，禁止自动认定其足以验证规律。

## D. 五台规律卡片：字段、文字与操作

五台固定独立卡片；过滤掉某台时显示“未选择”，不要伪造其结果。卡片有“时间规律”“环境关联”“空间/水层”“长期变化”标签，详细证据归入原规范六类规律，不新增一套互相矛盾的分类。跨站规律另有组卡，列出具体参与设备，不替代单设备卡。

| 卡片字段 | 最低要求 |
| --- | --- |
| 身份 | pattern_id、pattern_version、设备/站位、类别、研究阶段、run_id、规则与分析计划版本 |
| 结论 | 指标名称及单位；上升/高值/下降/低值/再升时段或其他条件；允许单峰、多峰、平坦、不能判断 |
| 适用边界 | 日期、日内时段、水层、环境范围、有效域、截断/安装/位置版本；不是普遍物种行为结论 |
| 效应 | 变化幅度、基线与单位；峰时/持续时间的分布和不确定性；仅有样本点时如实显示 |
| 证据 | 支持、反对、不确定、无法评价、处理错误的日期/时间块清单与数量；可以逐项打开 |
| 验证 | 发现期与独立验证期分列，验证状态、证据等级L0—L3、未满足条件、上次更新时间 |
| 质量 | 实际有效日数/日历日数、有效观测时长、覆盖、缺测、配置变更及主要局限 |
| 操作 | 查看支持日、查看反例、原始回波、比较版本、导出证据；人工备注保留作者和时间 |

示例模板（不能作为真实结果预填）：

> 设备{编号}在{日期范围及条件}内，{时段A}的{指标}较参考高{效应及单位}，随后在{时段B}下降，{时段C}再次回升。发现期{统计}；独立验证期{统计/尚未完成}。该规则在{支持数}/{可评价数}个日期中得到支持；反对{数}、不确定{数}、无法评价{数}。当前等级{L0—L3}，适用范围和局限为{内容}。

用户的“鱼多/鱼少”在界面中对应已验证的声学活动指标高/低；没有目标验证与标定时，报告不得把候选回波数直接改称真实鱼尾数。不能用“置信度85%”替代一个未经定义的支持比例。

无规律时必须区分：尚未运行、参数/指标阻断、样本不足、没有检出重复模式、已有规则被反例削弱、需要重新验证。不能把这些状态都显示成“无鱼”。

## E. 日内升高—减少—再升高怎样得到

### E1. 先登记分析计划

默认分析格可从15分钟起步，支持配置。分析计划至少固定：目标指标、时间格、每格有效覆盖门槛、参考期/基线、候选高/低阈值、最小持续格数、最小变化幅度、峰间分隔、允许缺口、午夜处理、峰匹配容差、开发与验证日期、误差与重复性判据、多重比较处理。参数从真实样本、标注和研究目的确定，不能把示例阈值当科学事实。

生产分析计划内关键字段未确定时，允许探索图和参数预览，但不能发布已验证规律。参数预览必须有“探索”标签，不直接成为论文冻结结论。

### E2. 可实现的首版流程

1. 获取硬截断后的统一指标格，同时保留每格分子/分母、覆盖、QC、安装版本。
2. 根据冻结参考期计算本台基线或时刻基线；阈值/标准化只从开发资料估计，不使用验证期未来信息。
3. 按预先选择的阈值或局部背景方案标记候选高值、低值与变化段；连续性、最小持续时长和最小效应共同约束，过滤短尖峰。
4. 高/低段必须由实际合格格支持。跨长缺口不连接，不通过插值创造第二峰；短缺口如允许连接，其长度上限和边界不确定性必须记录。
5. 上升/下降起止由已登记的变化判据确定，输出时间区间、变化幅度和分辨率；15分钟格不生成秒级转折精度。
6. 逐日生成事件表，允许无峰、单峰、多峰、平台、午夜跨界和不可判定。午夜时刻用环形或显式跨日区间处理，23:50与00:10不能机械平均成12:00。
7. 汇总时按日或合适独立时间块统计峰时、持续性和效应分布；不是把所有帧当独立重复。每台分别得到候选规律，再进行后续验证。

最少事件字段：device_id、local_anchor_date、event_type、start/end、peak_time及可识别精度、metric_id、baseline_version、effect_size、valid_duration、coverage、boundary_uncertainty、config/mask版本、source_window_ids、run_id。跨午夜事件归属规则全系统一致。

### E3. 验证不能只靠示例波形

合成双峰、多峰、平台、缺口和参数切换用于检验程序逻辑；真实片段另做人工复核，记录边界误差、漏检/误检、不同设备/噪声条件表现。未达到登记的验证标准时降级或标记阻断，不能只因为图上画出两个峰就通过。

## F. 规律证据与生命周期

### F1. 日期/时间块判定表

以预先约定的独立单位（完整日期、潮周期或合理时间块）评价，不以采样帧数量替代生态重复数。每个单位对同一冻结规则有一个主要状态。

| 状态 | 判定 | 分母处理 |
| --- | --- | --- |
| SUPPORT 支持 | 数据合格且满足预登记规则 | 进入可评价分母 |
| COUNTER 反对 | 数据合格，且满足预登记的否定/失败条件 | 进入可评价分母 |
| INCONCLUSIVE 不确定 | 数据足以评价，但效应/误差落入预登记不确定区间 | 进入可评价分母，不能隐藏 |
| UNEVALUABLE 无法评价 | 缺测、覆盖不足、配置不可比或必要环境缺失 | 不进入可评价分母，单列数量/原因 |
| ERROR 处理错误 | 计算失败或版本冲突，尚未得到合法判定 | 单列待处理，不能作为无法评价永久隐藏 |

可评价数=支持+反对+不确定；支持比例=支持/可评价数。可评价数0时比例NA。若另显示支持/(支持+反对)，必须命名“排除不确定后的支持比例”，同时展示被排除数；不能替换主比例。发现期和验证期各自计算，不混成一个总“成功率”。

例：某验证范围60天，支持35、反对8、不确定5、无法评价12、错误0，则可评价48，支持35/48≈72.92%。不能显示35/60为同一支持比例，也不能称“72.92%置信度”。缺测是否导致偏倚需讨论。

### F2. 等级与版本

- L0：没有足够证据可靠评价；可同时显示探索性候选，不隐藏阻断。
- L1：已观察到的初步模式，尚无充分多日重复/验证证据。
- L2：在多个合格独立单位重复，并通过质量、可比性和敏感性检查；最低重复数、效应与误差判据由计划冻结。
- L3：规则和判据在验证前冻结，在后续独立资料上达到预登记验证要求，并通过适用性检查；仍是限定条件下的阶段性模式。

等级不按7/30/60天自动升级，不等于p值，也不等于预测准确率。缺少明确判据时不得自动升级。生命周期状态另设CANDIDATE、FROZEN_FOR_VALIDATION、VALIDATING、SUPPORTED、WEAKENED、RETIRED、SUPERSEDED；状态与L等级分别存储，不能用“已冻结”冒充“已证实”。

新数据先评价旧规则，再单独发现新规则。参数调整、改变高峰时段或重新选择环境条件生成新规则版本，新规则的独立验证重新开始；不得事后改规则再宣称旧规则预测成功。旧报告、反例与已废弃版本都可回查。

## G. 空间、环境与水层规律的具体输出

| 类型 | 用户可读结论内容 | 必备证据与限制 |
| --- | --- | --- |
| 稳定空间差异 | 哪些站位在可比条件下指标长期较高，差异是否跨阶段保持 | 共同有效时间、每站有效域、日级配对差异、效应区间、支持/反对阶段；不能仅按阶段平均排名 |
| 站间同步/时差 | 哪些站同时变化，某站是否在预定滞后范围内经常领先 | 同期曲线、配对数、自相关/共同环境与多重检验处理、独立验证；不能认定同一群鱼迁移 |
| 钟点与潮相 | 高峰固定在钟点，还是随高潮/低潮时间移动 | 钟点与潮相两种对齐、涨/落潮区分、配对覆盖、模型诊断；不能把潮高直接当现场流速 |
| 温度/风关联 | 某条件范围内活动水平的关联及可能时间滞后 | 数据来源、实测/预报属性、单位、时间容差、0/1/2/3/6/12/24小时预设滞后及全部结果；不写因果结论 |
| 水层差异 | 在可观测层内的活动比例/事件率是否随昼夜或潮相改变 | 实际覆盖层界、投影与几何假设、每层分母、NA；不能把未覆盖层当没有鱼 |
| 长期模式变化 | 峰时漂移、持续时长变化、站位差异转变 | 参数变更/维护与覆盖变化先排查，给变点或趋势误差及适用期；不能把设备调整当生态规律 |

空间点颜色可以显示原始可比指标或“本台相对固定基线变化”，但两种视图标题和单位必须不同。本台标准化后的高分只表示相对自己变化大，不能据此声称该站鱼最多。

### I1. 共享查询状态

用一个版本化QueryContext驱动所有组件，至少包括：selected_devices、date_range/date_set、daily_windows、timezone、metric_id、depth_mode/layer、environment_filters、comparison_mode、baseline_id、aggregation_mode、grouping_mode、calendar_anchor、dataset_id、run_id、analysis_plan_version、parameter_versions、mask_version、color_scale_id。日期时区和参数快照不能由每个组件自行推断。

正在计算、新版本待重算、旧版本可查看必须分别标记。组件加载较慢时保留版本提示，不允许地图显示新run而卡片还显示旧run却伪装同一查询。任务取消不破坏已发布快照。

## K. 本次明确新增的强制规则摘要
